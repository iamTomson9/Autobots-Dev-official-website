## 🛠 Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES Modules)
- **Design System:** Custom CSS with glassmorphism, dark obsidian palette
- **Typography:** Outfit (headings) + Inter (body) — Google Fonts
- **Icons:** Font Awesome 6.5
- **Backend/DB:** Firebase Firestore + LocalStorage fallback
- **Auth:** Firebase Authentication
- **AI Chatbot:** Custom Gemini-powered assistant (`js/chatbot.js`)
- **Hosting:** Vercel
